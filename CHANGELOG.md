# Changelog

This document records notable completed changes to MusicPlayer.

## [Unreleased]

### Added

- Initial React Native 0.87.1 application scaffold.
- Android and iOS project directories generated by Community CLI.
- TypeScript, Jest, and ESLint configuration.
- npm dependency lockfile.
- Project README and contributing guidelines.
- Architecture decision defining feature organization and dependency boundaries.
- Playlist name validation and trimming, with unit tests.
- Playlist data model and repository contract.
- Playlist creation use case with injected dependencies and unit tests.
- In-memory playlist repository and integration tests for playlist creation.
- OP-SQLite 18.2.5 dependency for local database integration.
- SQLite diagnostics for Android development builds.
- ADR writing guidelines and an architecture decision index.
- Architecture decision defining the playlist storage schema and migration rules.
- Playlist database relationship diagram and diagram writing guidelines.
- Initial playlist schema migration definition with SQLite integration tests.
- Versioned SQLite migration runner with per-migration transactions and unit and integration tests.
- Source alias configuration, automated import sorting, import lint rules, and formatting scripts.
- Application database initialization with migration readiness checks and connection cleanup on failure.
- GitHub Actions workflow for formatting, linting, TypeScript checks, and unit and integration tests.
- Native database initialization on application startup, with shared connection loading and retry support.
