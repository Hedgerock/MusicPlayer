# ADR-0002: Постоянное хранение данных в SQLite

## Статус

Предложено.

## Контекст

Плейлисты должны сохраняться после перезапуска приложения.

Приложение развивается в сторону музыкальной библиотеки, плейлистов и истории воспроизведения. Эти данные содержат связи
и требуют сохранения порядка.

Репозиторий в памяти используется для быстрых тестов. Для пользовательских данных требуется постоянное хранилище.

## Решение

Приложение использует локальную базу данных SQLite.

Доступ к SQLite выполняется через библиотеку @op-engineering/op-sqlite.

База содержит метаданные приложения. Аудиофайлы остаются отдельными файлами на устройстве.

SQLite-репозиторий реализует существующий контракт PlaylistRepository.

Работа с библиотекой, SQL-запросами и миграциями размещается в infrastructure.

Слои domain и application сохраняют независимость от конкретной библиотеки хранения.

Точка сборки приложения связывает сценарии с SQLite-репозиторием.

Структура базы изменяется через версионированные миграции. Пользовательские значения передаются в SQL через параметры.

Выбранная версия библиотеки фиксируется в package.json и package-lock.json.

## Проверка решения

Подключение проверяется сборкой Android-приложения.

Работа драйвера проверяется выполнением SQL на эмуляторе или устройстве.

Сохранность данных проверяется записью, перезапуском приложения и последующим чтением.

Решение переводится в статус "Принято" после успешной проверки подключения и работы базы на Android.

## Последствия

- Данные доступны между запусками приложения.
- Работа хранилища не требует подключения к интернету.
- Проект получает нативную зависимость.
- Изменения нативной зависимости требуют пересборки приложения.
- Схема базы и миграции требуют отдельных проверок.
- Репозиторий в памяти сохраняется для быстрых тестов.

## Рассмотренные альтернативы

### Репозиторий в памяти

Используется в тестах. Данные существуют в течение жизни экземпляра.

### expo-sqlite

Предоставляет доступ к SQLite. Подключение к существующему React Native проекту требует установки Expo.

Для текущего Community CLI выбран OP-SQLite.
