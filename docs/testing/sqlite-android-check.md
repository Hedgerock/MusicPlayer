# Проверка работы хранения данных на Android

Документ фиксирует ручную проверку записи, чтения и сохранности данных SQLite после перезапуска Android-приложения.

Сценарии диагностического экрана относятся к этапу начальной интеграции SQLite.

После подключения экрана плейлистов используются
[проверки пользовательских плейлистов](playlists-android-check.md).

Результаты ниже сохраняются как история выполненных проверок.

## Проверка решения

Подключение проверяется сборкой Android-приложения.

Работа драйвера проверяется выполнением SQL на эмуляторе или устройстве.

Сохранность данных проверяется записью, перезапуском приложения и последующим чтением.

## Сценарий проверки

Дано: debug-сборка приложения запущена на Android.

Когда:

1. Пользователь нажимает "Проверить хранилище" и фиксирует значение счётчика.
2. Процесс приложения завершается командой `adb shell am force-stop com.musicplayer`.
3. Пользователь открывает приложение через иконку и повторно нажимает "Проверить хранилище".

Тогда: значение счётчика увеличивается на единицу относительно зафиксированного значения.

## Проверка запуска рабочей базы

Дано: debug-сборка приложения установлена на Android.

Когда:

1. Пользователь запускает приложение через иконку.
2. Приложение завершает инициализацию рабочей базы.
3. Пользователь завершает процесс командой `adb shell am force-stop com.musicplayer`.
4. Пользователь повторно запускает приложение через иконку без очистки данных.

Тогда:

- После каждого запуска отображается экран "Проверка хранилища".
- Инициализация выполняется автоматически, без нажатия диагностической кнопки.
- Ошибка подготовки приложения отсутствует.
- Приложение остаётся доступным для взаимодействия.

Рабочая база использует файл `music-player.sqlite`.

Кнопка "Проверить хранилище" использует отдельную диагностическую базу. Значение её счётчика не является результатом проверки
рабочей базы.

Обработка ошибки и успешная повторная попытка дополнительно проверяются компонентными тестами.
