# Проверка плейлистов на Android

Статус: Пройдена.

Документ фиксирует создание пользовательских плейлистов, сохранность данных после перезапуска процесса и доступность интерфейса.

## Подготовка

Приложение собрано и установлено после подключения нативного источника случайных байтов.

Существующие данные приложения сохраняются.

## Создание плейлистов

Дано: приложение запущено, экран плейлистов загрузился.

Когда:

1. Пользователь отправляет пустое название.
2. Пользователь создаёт плейлист с названием " Дорога ".
3. Пользователь создаёт ещё один плейлист с названием "Дорога".

Тогда:

- Пустое название сопровождается сообщением "Введите название плейлиста".
- Успешное создание сопровождается сообщением с сохранённым названием.
- Пробелы по краям названия удаляются.
- После успешного сохранения поле очищается.
- Каждый успешно созданный плейлист отображается отдельной записью.

## Перезапуск процесса

Дано: пользователь создал плейлисты и зафиксировал состав списка.

Когда:

1. Пользователь выполняет `adb shell am force-stop com.musicplayer`.
2. Пользователь запускает приложение через иконку без очистки данных.
3. Пользователь создаёт ещё один плейлист.

Тогда:

- Ранее созданные плейлисты доступны после загрузки списка.
- Повторяющиеся названия сохраняются отдельными записями.
- Создание нового плейлиста после перезапуска завершается успешно.

## Увеличение шрифта

Дано: включён максимальный системный размер шрифта.

Когда: пользователь просматривает список, вводит длинное название и создаёт плейлист.

Тогда:

- Названия и сообщения остаются читаемыми.
- Текст не обрезается фиксированной высотой.
- Поле и кнопка доступны при открытой клавиатуре.
- Содержимое экрана можно прокрутить.

## TalkBack

Дано: включён TalkBack.

Когда: пользователь последовательно проходит элементы экрана и создаёт плейлист.

Тогда:

- Заголовки, поле и кнопка имеют понятные названия и роли.
- Порядок фокуса соответствует интерфейсу.
- Создание доступно через кнопку "Создать".
- Сообщения об ошибке и успешном создании доступны экранному диктору.
